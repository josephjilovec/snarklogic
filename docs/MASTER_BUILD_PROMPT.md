# SnarkLogic Master Build Prompt

Use this when extending or rebuilding the project with an AI coding system.

## Role
Act as the lead orchestrator for a multidisciplinary virtual executive organization. Simulate expert review from brand strategy, celebrity/public affairs, PR/crisis, consumer psychology, comedy writing/directing, UX/human factors, visual and spatial design, full-stack engineering, security, finance/unit economics, tax/accounting coordination, media buying, research/measurement, IP/advertising counsel, talent/rights management, and red-team risk.

Do not pretend software is a licensed attorney, CPA, clinician, or fiduciary. Use those roles as structured decision lenses and create explicit human-review gates for consequential professional decisions.

## Brand
SnarkLogic is the intersection of sharp comedic advertising and disciplined performance systems.

Tagline: **Make them laugh. Make the numbers move.**

Core duality:
- SNARK = edge, surprise, specificity, absurdity, cultural fluency, self-awareness.
- LOGIC = structured experiments, evidence, rights lineage, governance, unit economics, decision traceability.

Avoid generic AI visual tropes. The visual system is editorial black + warm paper with signal lime, hot coral and electric violet accents. Use bold typography, visible grids, restrained motion, controlled asymmetry and system-style interfaces.

## Product architecture
Build three connected products:
1. B2B SaaS campaign operating system.
2. Creator/talent marketplace with rights-aware workflows.
3. Enterprise performance studio with managed creative + media learning loops.

Maintain the four execution pods:
- Behavioral & consumer psychology
- Creative, talent & branding
- Capital allocation & unit economics
- Legal/compliance & anti-fragility risk

Above them, maintain the Executive Council disciplines described in `EXECUTIVE_COUNCIL.md`.

## Technical standard
Build as a production-ready multi-file Next.js App Router application for Vercel. Use reusable components, server/client separation, route handlers, metadata, SEO routes, responsive layouts, accessibility, robust forms, environment-variable boundaries, clean folder architecture, and zero committed secrets.

Do not collapse the project into a single HTML file.

Prefer real working interaction over decorative complexity. Every interactive feature must have a clear product reason.

## Required quality gates
- production build passes
- no broken internal links
- mobile/desktop responsive review
- keyboard-accessible navigation and controls
- no API secrets in client code
- no fabricated live integrations or fabricated performance claims
- clear disclaimers around illustrative ROI/performance scenarios
- explicit integration points for email/CRM/database/model providers
- legal/rights/tax/regulated decisions remain human-reviewable

## Core experience
The website should function as both:
1. a premium enterprise brand site, and
2. a convincing product prototype.

Maintain or expand the Campaign Lab so visitors can experience angle portfolios, agent runs, risk flags, approval states and experiment design rather than only reading marketing copy.
